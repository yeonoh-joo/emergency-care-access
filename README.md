# 수도권 응급의료 접근성 분석

공공데이터를 이용해 서울·경기·인천의 시군구별 응급의료 접근성을 비교하고, 인구 대비 응급의료기관이 부족한 지역을 찾아본 분석 프로젝트입니다. (시스템분석설계 수업 미니프로젝트)

## 1. 프로젝트 개요

- 목적: 시군구 단위로 인구 대비 응급의료기관 수를 계산해 응급의료 취약 가능 지역 탐색
- 분석 대상: 서울특별시, 경기도, 인천광역시 (66개 시군구)
- 사용 기술: Python, pandas, numpy, requests, xmltodict, python-dotenv, Jupyter Notebook

## 2. 데이터

| 데이터 | 출처 | 형태 | 사용 항목 |
|---|---|---|---|
| 응급의료기관 정보 | 공공데이터포털 응급의료기관 정보 조회 오픈 API | XML (API) | 기관명, 전화번호, 주소, 위도, 경도 |
| 지역별(행정동) 성별 연령별 주민등록 인구수 | 공공데이터포털, 행정안전부 | CSV | 시도명, 시군구명, 전체 인구, 연령별 인구 |

- 응급의료기관 195곳을 수집했습니다. (서울 72, 경기 96, 인천 27)
- 인구 데이터 기준월: **(기준월 입력)**
- 인구 CSV는 `data/` 폴더에 포함되어 있으며 인코딩은 cp949입니다.
- 두 데이터셋 모두 공공데이터포털에서 제공하며, 인구 데이터의 이용허락범위는 "제한 없음"입니다.

## 3. 분석 방법

1. 오픈 API로 3개 시도의 응급의료기관 목록을 수집
2. 기관 주소에서 시군구를 추출해 시도·시군구별 기관 수 집계
3. 인구 CSV에서 행정동 단위 인구를 시군구 단위로 합산하고, 65세 이상 인구도 함께 계산
4. 두 데이터를 시도·시군구 기준으로 병합 (기관이 없는 지역은 0으로 처리)
5. **인구 10만 명당 응급의료기관 수** = 기관 수 ÷ 인구 × 100,000
6. 이 값이 **0.6 미만**인 시군구를 취약지역으로 분류

> 취약지역은 이 분석에서 정한 기준에 따른 분류이며, 공식 응급의료취약지 지정과는 별개입니다.

## 5. 해석 및 한계

**해석**
- 인구 대비 응급의료기관 수는 지역별로 차이가 있었습니다.
- 고령 인구가 많은 지역에서 기관이 부족하면 응급 상황 대응이 늦어질 수 있어 추가 확인이 필요합니다.

**한계**
- 기관 수만 집계했고 병상 수, 의료진 규모, 응급실 이용 가능 여부는 반영하지 못했습니다.
- 기관 등급(권역·지역센터·지역기관) 구분 없이 단순 개수로 비교했습니다.
- 거리나 이동 시간 같은 지리적 접근성은 고려하지 않았습니다.
- 65세 이상 인구는 계산했지만 취약지역 판정 기준에는 사용하지 않았습니다.
- 한 시점의 데이터라 시간대별 수요 변화는 반영하지 못했습니다.
- 주소 문자열에서 시군구를 추출해 병합했기 때문에 일부 지역은 매칭 오차가 있을 수 있습니다.

## 6. 실행 방법

1. 라이브러리 설치

```bash
pip install pandas numpy requests xmltodict python-dotenv jupyter
```

2. 공공데이터포털에서 응급의료기관 정보 조회 API 활용 신청 후 인증키 발급
3. 프로젝트 폴더에 `.env` 파일을 만들고 키 입력

```
d_key=발급받은_인증키
```

4. `data/` 폴더에 인구 CSV가 있는지 확인한 뒤 `미니프로젝트2.ipynb`를 위에서부터 실행

> `.env`는 `.gitignore`에 추가해 저장소에 올리지 마세요.
